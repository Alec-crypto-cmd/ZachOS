# Branding

This folder is the easy customization point for the visible ZachOS identity.

- Replace `zachos-logo.svg` with your logo.
- Replace `zachos-wallpaper.svg` with your wallpaper.
- Update the colors in `branding/theme.conf`.
- Keep filenames stable so the build does not need any other changes.

For a PNG or JPG wallpaper, place it here and update the wallpaper path in `airootfs/etc/skel/.config/plasma-org.kde.plasma.desktop-appletsrc`.
